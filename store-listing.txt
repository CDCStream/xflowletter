─── NAME ───
X Flow Teller — Read X Posts Aloud

─── SHORT DESCRIPTION (132 chars max) ───
Reads your X feed aloud with Chrome voices, 35 language hints. TTS runs locally; license checks use Polar.sh.

─── DETAILED DESCRIPTION ───
X Flow Teller reads your X (formerly Twitter) timeline out loud — post by post, hands-free. Speech uses your browser’s built-in text-to-speech (Web Speech API), not a cloud TTS service.

NOT AFFILIATED: This extension is not affiliated with, endorsed by, or sponsored by X Corp. or Twitter.

HOW IT WORKS
1. Install the extension and open x.com or twitter.com.
2. A floating control panel appears at the bottom-right.
3. Press Play. Posts with visible text are read one by one; the page may scroll to load more.
4. Use Skip on a post to skip it, or Pause / Stop anytime.

FEATURES
• Multi-language voices — heuristics suggest a language for Chrome’s voices; many languages are supported where the OS/browser provides voices; others fall back to English.
• Local speech synthesis — audio is generated in your browser via the Web SpeechSynthesis API. Tweet text is not sent to a third-party TTS API.
• Optional license — free tier with a daily read limit; purchase a lifetime license at xflowteller.com. Activating a key contacts api.polar.sh over HTTPS (license key only for that request).
• Infinite-style reading — when no new unread posts are visible, the extension scrolls to try to load more.

PRICING
• Free tier: limited reads per day, no sign-up required.
• Lifetime license: one-time payment for unlimited reads at xflowteller.com.

PRIVACY
Tweet content is processed locally for speech. License activation/validation uses Polar.sh as described on https://xflowteller.com/privacy
